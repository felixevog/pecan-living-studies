# PECAN Living Study Overview

This repository provides a **continuously updated overview of studies using Perceived Causal Networks (PECAN)**. It accompanies the PECAN Guidelines and replaces the previously maintained living version hosted on the Open Science Framework (OSF).

The purpose of this page is to keep the study overview current as new PECAN studies are published, released as preprints, or otherwise become publicly available.

## How to cite this resource

Please cite the PECAN Guidelines rather than this repository:

**Vogel et al. (2026). _How perceived causal networks can complement case conceptualization, diagnostic classification, and data-based networks._**

[View the PECAN Guidelines on APA PsycNet](https://psycnet.apa.org/record/2026-51851-001)

## Scope

The overview includes studies that use PECAN to assess person-specific perceived causal relations between psychological problems, symptoms, or related experiences. Depending on the study, PECAN may be used for assessment, case conceptualization, comparison with other network approaches, prediction, treatment planning, or methodological development.
